# SEU Campus Lost & Found System

A web-based platform for Southeast University students to report, search, and recover lost items.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Features
- Student registration and email verification
- Login and authentication
- Report lost and found items
- Search and filter items
- Claim requests
- Admin dashboard
- Email notifications
